# Organize a raw capture

Use when the user asks to organize a note or capture. Read only the specific source they identify under `raw/`. Preserve its meaning and distinguish sourced facts from interpretation. Create one concise durable article under `wiki/` with a descriptive filename, useful headings, and links to related notes when known. Add a link under the right heading in `wiki/_master-index.md`. Return a short summary and paths changed. Do not invent facts or rewrite the original capture.
