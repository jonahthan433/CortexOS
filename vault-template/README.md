# CortexOS Vault

This folder is the shared memory layer for CortexOS and Obsidian.

- `raw/` — capture anything here.
- `wiki/` — organized, indexed reference notes.
- `output/` — generated deliverables.
- `requests/` — request logs (one predictable file per request ID).
- `receipts/` — run outcome receipts.
- `metrics/` — user-entered metrics.

See `AGENTS.md` for the rules each AI backend must follow.
